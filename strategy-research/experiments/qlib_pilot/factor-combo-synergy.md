# 因子协同效应搜索：2 因子与 3 因子组合（2008-2026）

> 数据范围：2008-2026，long-only Top-100 月度再平衡，单边 30bp 成本
> 方法：对 14 个 Barra 风格因子（剔除仅 0.5 年覆盖的大单资金流）穷举
> C(14,2)+C(14,3)=455 种组合，用月度快速回测打分，按 Sharpe 与滚动 36 月
> 赔率双指标排名，寻找因子协同效应（组合是否优于成分因子）。

## 一、最强协同：小盘 + 低换手

| 序列 | Sharpe | 年化 | 滚动36月赔率 |
| --- | ---: | ---: | ---: |
| 小市值（size）单因子 | 0.60 | 14.5% | — |
| 低换手（liquidity）单因子 | 0.40 | 7.5% | — |
| **小盘 + 低换手（2因子）** | **1.04** | **30.0%** | **16.1** |

小盘与低换手单独使用 Sharpe 只有 0.60 和 0.40，合成后跃升至 1.04，年化从 15%
翻倍到 30%。这是整套搜索中最强的协同效应，1+1 远大于 2。

## 二、加第三个因子没有增益

| 组合 | Sharpe | 年化 | 滚动36月赔率 |
| --- | ---: | ---: | ---: |
| **小盘 + 低换手** | **1.04** | **30.0%** | **16.1** |
| 小盘 + 低换手 + 质量 | 1.02 | 29.9% | 6.8 |
| 小盘 + 低换手 + 筹码集中度 | 0.98 | 27.6% | 11.5 |
| 小盘 + 低换手 + 低波动 | 0.80 | 20.1% | 5.7 |
| 小盘 + 低换手 + 低杠杆 | 0.80 | 21.6% | 6.2 |

双因子（小盘 + 低换手）已经是收益与胜率的最优平衡点。添加任何第三个因子要么
基本中性（质量），要么稀释收益（低波动、低杠杆、成长、价值）。滚动赔率甚至
普遍下降（从 16.1 降到 5-11）。

## 三、小盘是协同的核心

所有 Sharpe 排名靠前的组合都包含小盘（size）因子：

- 前 15 名中 14 个含 size，唯一例外是小盘外的双因子最佳（value+quality，Sharpe
  仅 0.38）。
- 不含 size 的三因子最佳组合（低换手 + 筹码 + 质量）Sharpe 只有 0.55，远低于
  任何含 size 的组合。
- 不含 size 与低换手的双因子组合全部很弱（Sharpe 0.35-0.38）。

小盘因子是整套组合协同效应的主导来源，低换手是它的最佳搭档。

## 四、协同效应的层次

| 层级 | 组合 | Sharpe |
| --- | --- | ---: |
| 强协同 | 小盘 + 低换手 | 1.04 |
| 弱协同 | 小盘 + 质量 | 0.71 |
| 弱协同 | 小盘 + 筹码集中度 | 0.64 |
| 弱协同 | 低换手 + 质量 | 0.56 |
| 无协同 | 小盘 + 低杠杆 | 0.55 |
| 无协同 | 小盘 + 盈利收益率 | 0.48 |
| 弱/无 | 不含 size/liquidity 的双因子 | 0.35-0.38 |

协同效应只在小盘与其他因子之间显著出现，且以小盘 + 低换手为最强。

## 五、结论

1. 最强因子组合是小盘 + 低换手（Sharpe 1.04，年化 30%，滚动36月赔率 16.1），
   存在明确协同效应，显著优于任一成分因子。
2. 双因子已是最优，添加第三因子无增益甚至稀释。不存在能大幅超越小盘 + 低换手
   的三因子协同组合。
3. 小盘是协同的核心，低换手是最佳搭档。其他因子与小盘的协同较弱，彼此之间
   几乎没有协同。
4. 这与之前两因子深度分析的结论一致：小盘 + 低换手（无成长）是最值得落地的
   组合，且其优势来自成分因子真实的多头 alpha，而非复杂组合。
