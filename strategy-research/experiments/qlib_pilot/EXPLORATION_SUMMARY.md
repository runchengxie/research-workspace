# A 股策略探索总结（2026-08）

> 日期：2026-08-10
> 范围：从 qlib 框架评估到策略、回测、回撤根因、市场直觉、因子归因与三因子策略的完整探索
> 目的：沉淀这一长串探索的发现、被推翻的结论和未来方向

## 一、起点：qlib 框架评估

### 问题
是否值得引入 qlib / LEAN / vn.py / backtrader，替代自研框架。

### 发现
- qlib 训练后端与自研原生等价（IC 差异 +0.003，可忽略）。
- qlib 的 IC 优势来自预处理管线（横截面标准化），不是模型训练。
- 原生 robust 标准化（中位数/MAD）复刻后，月频下稳定提升约 0.02，无需 qlib 依赖。
- LEAN / vn.py / backtrader 无增量价值，维持不引入。

### 结论
不引入 qlib。robust 标准化已并入原生（alpha-research #15），作为生产默认。

## 二、策略特征与权重

### 风格因子入模型特征（已推翻）
- 5 日标签下加风格因子（低换手/价值）无效。
- 月频（20 日）标签下风格因子不再拖累，但也不提升。
- 结论修正：风格因子是长周期信号，应作组合层暴露约束，不作短期模型特征。

### 等权 vs signal 加权
- signal 加权在全市场反而更差（Sharpe -1.08 vs 等权 0.54）。
- 信号无效时集中加权放大噪声，等权更稳。

## 三、全市场回测（核心）

### 关键变量
| 变量 | 影响 |
| --- | --- |
| top_k | 5 太集中，30 分散（回测 Sharpe 0.54 -> 2.69） |
| 资金量 | 100 万 vs 1000 万冲击差异巨大 |
| 执行参数 | VWAP 拆单提升成交率（51% -> 88%） |
| 验证期 | 短（5 个月度）OOS IC ~0，长（12 个月）OOS IC 0.10 |

### 被推翻的结论
1. "全市场 OOS 信号差（IC ~0）"——部分推翻。短验证期的 ~0 是假象，长验证期
   explore_valid_window 得全市场 IC 0.10；但严格评估（长验证期 + 真实执行）下
   全市场组合仍亏（Sharpe -0.44），OOS IC -0.015。乐观的 0.10 是特定窗口假象。
2. "top1200/1800 不值得"——错。100 万资金下流动性不是约束。
3. "标签泄漏是过拟合主因"——错。purge 无改善。
4. "top800 只是执行层便利"——错。top800 是信号层必要（见下）。

### 保留的结论
1. top_k=5 集中持仓在长周期不赚钱（Sharpe -1.41）。
2. 分散（top_k=30）显著优于集中。
3. **top800 流动性过滤救回信号**：同一套严格评估下，top800 回测 Sharpe +1.41
   （执行后 +0.84），全市场 -0.44（执行后 -0.90）。Q 组单调排名正确
   （Q1 4.92% -> Q5 3.32%），线性 IC 近零只因未捕捉排序能力；小盘极端收益
   噪声是全市场拖累主因。这是整条线第一个严格评估下赚钱的结果。
4. **top800 信号稳健**：4 个不同数据起点（2022-01/06/11、2023-04）全部正收益
   （回测 Sharpe 0.71-1.41，执行后 0.58-1.16），不是单段运气；但强度随起点
   递减，信号在衰减未消失。

## 四、top800 因子归因（2026-08-10）

### 方法
顶层 style_factors OLS 归因：top800 v2 策略日收益回归到 15 个因子 long-short 收益。

### 关键发现
1. **R²=0.52，annual_alpha=-11.51%**（2025 -6.94%，2026 -37.67%，均负）。
   top800 策略收益主要来自因子暴露（beta 偏低贝塔 β=-2.2 贡献 +40%、growth
   β=+1.3 贡献 +15~19%），不是选股 alpha。
2. **size 暴露方向与 exposure_screen 相反**：OLS 归因 size β=+0.42（偏大盘），
   exposure_screen 显示 -2.97（偏小盘）。后者是"相对 cap 加权基准"的尺度假象
   （任何非超大盘组合相对它都显示偏小）。归因 β 才是真实暴露方向。
3. **"修复 size 暴露"优先级下调**：真正常见的收益驱动是 beta/growth 暴露，
   不是 size。
4. **eval IC +0.086 可能捕捉的是风格趋势**而非独立选股能力（alpha 为负）。

## 五、三因子策略（小盘+低换手+成长）

### 因子方向修正
2008-2026 全市场因子分析（18 年）最强的三个因子（小盘方向理解）：
- **低换手**：Sharpe 1.56
- **小盘**（-size 大市值多空）：Sharpe 1.35（即做多小盘做空大盘）
- **成长**：Sharpe 1.28

size 因子定义为"大市值多空"，其负 Sharpe（-1.35）反过来就是**小盘因子正收益
+1.35**。此前误读为"小盘最差"，实为方向混淆。

### 三因子对照 top800 ML（2019-2026，含 10bps 成本）

| 指标 | 三因子 | top800 ML |
| --- | --- | --- |
| 总收益 | +527% | +52% |
| 年化 | +27.4% | +39.1% |
| Sharpe | **1.19** | 1.16 |
| 最大回撤 | -20.4% | -13.4% |

三因子 Sharpe 达到甚至略超 ML 模型，且透明可解释。6/7 年正收益。

### 稳定性（4 起点）
2019/2020/2021/2022 起点 Sharpe 分别为 1.19/1.14/1.22/1.01，4/4 稳健，比
top800 ML（0.71-1.41）更稳定。

### 权重优化（2021 起点）
- **重小盘（2/1/1）最优**：Sharpe 1.53（等权 1.22）
- **成长必需**：去掉成长 Sharpe 崩到 0.30
- **小盘主导**：去掉小盘 0.90，翻倍权重 1.53
- **低换手辅助**：去掉仍 1.27，加重反降

### 2026 小盘逆风（结构性信号）
- **2026 是 18 年来 size 因子首次转正**（+2.4）：2008-2025 连续为负（小盘持续
  跑赢），2026 首度转正，是结构性转变早期信号。
- 三因子 2026 转负（-12%）正是小盘因子转正的反映。
- 应对：加小盘暴露上限约束，或密切跟踪 2026H2-2027 size 因子。

### 三因子 long-only 落地（2008-2026，含成本与交易限制）

三因子此前研究是 Q5-Q1 多空价差。落地形态（纯多头、Top-100、月度再平衡、
次交易日成交、单边 30bp 成本）收益显著低于价差，且随时间衰减：

| 变体 | 2008-2026 年化 / Sharpe | 2015-2026 年化 / Sharpe | top800 2015-2026 |
| --- | --- | --- | --- |
| 复合三因子 | 15.0% / 0.62 | 6.8% / 0.37 | -6.2% / -0.04 |
| 小市值 | 14.5% / 0.60 | 6.9% / 0.37 | -17.0% |
| 低换手 | 7.5% / 0.40 | -3.4% | -6.4% |
| 成长 | 1.5% / 0.20 | 0.1% | -7.7% |

关键发现：
- 2008-2026 复合多头年化 15%（Sharpe 0.62），主要来自小市值与低换手。
- 收益随时间衰减：同口径 2015-2026 年化仅 6.8%，2017 后小市值/低换手风格回撤。
- top800 大票池内三因子全部失效（转负），alpha 集中在中小市值段。
- 相比 Q5-Q1 价差（低换手全周期年化 26%），long-only Top-100 只有 7.5%，
  价差研究高估可实现收益。

数据依赖：成长因子 2008 起数据来自回填的 fundamentals vintage
（vintage=20260819），使三因子 2008 起即可计算。详见
long_only_style_analysis.md。

## 七、市场直觉（2008-2026 等权）

- 星期五不弱（+0.003%），周四弱（-0.065%）。"周五跌"是假的。
- 连涨 3 天后第 4 天更易涨（胜率 59.5% vs 55.6%）。3 日动量。
- 最差 10 交易日：2015 股灾占 6 个，5 个周一，次日 90% 继续跌。

## 八、核心教训

1. **评估方法决定结论**：验证期、资金量、数据窗都能翻转结论。任何策略判断
   必须先确认评估设计可靠。短验证期曾同时得出"全市场 OOS IC 0.10"和
   "top_k=5 Sharpe 0.54"两个事后证明不可靠的结论。
2. **集中持仓 vs 分散**：分散（30 只）显著优于集中（5 只）。
3. **信号 vs 执行**：VWAP 解决成交率，解决不了信号质量。
4. **风格约束**：风格因子作组合约束，不作模型特征。
5. **universe 决定信号**：同样模型下全市场亏、top800 赚。流动性过滤是信号层
   必要，不是执行层便利。
6. **因子方向必须核对**：size 因子定义为大市值多空，负 Sharpe 反读为小盘因子
   正收益。因子归因 β 与 exposure_screen 读数可相反（基准尺度不同），以归因
   β 为准判断真实暴露。
7. **ML 收益 ≠ 选股 alpha**：top800 ML 策略 alpha 为负，收益来自 beta/growth
   因子暴露。显式因子组合（小盘+低换手+成长）可比 ML 更好且透明。
8. **小盘时代可能转折**：2026 是 18 年首次 size 因子转正，重小盘策略需加暴露
   约束并密切跟踪。

## 九、未来方向

1. **三因子策略落地**：小盘+低换手+成长显式组合，权重 2/1/1 优化，加小盘暴露
   上限约束应对 2026 转折。是 top800 ML 的透明替代。
2. **2026 小盘逆风跟踪**：确认 size 因子转正是短期还是长期趋势，决定小盘权重
   是否调整。
3. **组合优化**：top800 + top_k=30 + 风格暴露约束（重 beta/growth 而非 size），
   确认约束不破坏收益。
4. **D11-H5 修复**：加风格约束压回撤，并评估三因子信号是否更适合。
5. **市场探索**：纯理解类已跑完（星期五/连涨/最差日）；策略相关类（追涨/高股息/
   市盈率/金叉）在评估稳定后做。
6. **qlib 方法**：样本过滤、集成、PIT 对齐可作为改进参考（已记录 qlib_methods_borrow.md）。
