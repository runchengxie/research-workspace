## 核心结论

### 1. size 暴露是负贡献，且方向与 exposure_screen 读数相反

- exposure_screen 的 size_active_net_vs_cap = -2.97 显示"偏小盘"（相对 cap 加权基准）
- OLS 归因 size β = +0.42 显示**偏大盘**（相对因子 long-short）
- 2025 年 size 贡献 **-8.33%**（偏大盘暴露在大盘跑输小盘时亏钱）

矛盾的解释：exposure_screen 的基准是市值加权（极端偏大盘），任何非超大盘组合都显示"偏小"；
OLS β 的基准是小盘−大盘因子收益。两者衡量不同维度的暴露。归因（β 和贡献）更能反映
"暴露对收益的真实影响"。

### 2. 策略收益主要来自因子暴露，不是选股 alpha

- 2025 alpha -6.94%，2026 alpha -37.67%，整体 -11.51%（均为负）
- R² 0.52-0.56，因子解释过半收益
- **最大贡献因子是 beta（偏低贝塔）**：β≈-2.2，在低贝塔因子负收益的年份贡献 +40%
- growth 也是重要正贡献（+15% 到 +19%）

### 3. 对"top800 信号有效"结论的修正

- 之前的 eval IC +0.086（显著）和 CPCV sharpe_median 1.01，现在看**部分是因子暴露
  的体现**（beta 偏低贝塔 + growth 偏成长），不全是独立选股能力
- 剔除因子后 alpha 为负，意味着"纯选股能力"是**负的**
- 但注意：alpha 为负不等于策略不赚钱——策略靠因子暴露赚钱，这是风格策略的常态

### 4. 关键差异：为什么之前评审显示信号有效？

- 之前用 eval IC（横截面排序）评估，IC 正说明"预测收益排序有效"
- 归因用收益分解，alpha 负说明"剔除风格后没有超额"
- 两者不矛盾：策略可能在"选对风格"（IC 捕捉到风格趋势），但风格本身在 2025-2026
  是逆风（低贝塔/成长因子都走弱），所以 alpha 被因子收益吞噬

## 对下一步的影响

1. **"修复 size 暴露"的优先级需下调**：size 贡献负（-8.33%），但归因显示策略实际
  偏大盘（β+0.42），并非 exposure_screen 暗示的"小盘赌注"。是否调整取决于对
  大盘/小盘走势的判断，不是机械修复。
2. **beta/growth 暴露才是主要收益来源**：-2.2 beta 和 +1.3 growth 贡献了大部分收益。
   若担忧风格回撤（低贝塔因子转正时），这才是需要关注的暴露。
3. **annual_alpha 为负是真实信号**：如果目标是"独立选股 alpha"，当前策略不达标。
   若目标是"风格策略"（赚因子钱），则 alpha 负可接受，但要管理风格风险。
4. **后续**：可对比 baseline（全市场）的归因，看 top800 是否相对 baseline 改善了
   alpha（而非只看绝对 alpha）。
