# top800 衰减诊断：是市场状态，不是信号衰减（2026-08-10）

## 背景与方法

top800 稳定性验证显示回测 Sharpe 随起点递减（2022-01 1.41 → 2023-04 0.71）。
本诊断判断这是信号结构衰减还是评估窗口差异。复用 4 起点回测日志（top_k=30、
长验证期、真实执行），对照等权市场日收益与各起点训练/测试段。

## 关键事实

### 1. 测试段是同一段市场（都锚定 end）

| 起点 | 训练月数 | 测试段 |
| --- | ---: | --- |
| 2022-01 | 46 | 2025-11 → 2026-08 |
| 2022-06 | 42 | 2025-12 → 2026-08 |
| 2022-11 | 38 | 2026-01 → 2026-08 |
| 2023-04 | 34 | 2026-02 → 2026-08 |

所有起点测试段几乎重叠（2025Q4-2026Q2），"递减"来自训练窗口长度差异，非测试时间差异。

### 2. 测试段是 2021 以来最弱的市场段

等权市场日收益：训练段 +21% 到 +31%，测试段 +24% 到 -16%。2022 高波动（vol 50%），
2026 走弱（等权 cum +3.2%）。

### 3. 模型本身没有衰减

Train Daily IC 稳定：0.245 / 0.237 / 0.233 / 0.224，无明显下降。若信号衰减，
训练 IC 也会下降。

### 4. Q 组排序能力随训练窗口缩短退化

| 起点 | Q1 | Q5 | Q1-Q5 spread | 回测 Sharpe |
| --- | ---: | ---: | ---: | ---: |
| 2022-01 (46mo) | 4.92% | 3.32% | +1.60pp | +1.41 |
| 2022-06 (42mo) | 3.38% | 2.57% | +0.80pp | +1.26 |
| 2022-11 (38mo) | 3.49% | 2.51% | +0.98pp | +0.83 |
| 2023-04 (34mo) | 4.02% | 4.09% | -0.07pp | +0.71 |

长训练窗口 Q 组严格单调（Q1 4.92% > Q5 3.32%），短窗口单调消失（2023-04 的 Q5
反超 Q1）。

### 5. 特征重要性随训练窗口变化

2022-01 起点 macd_hist 0.089（动量主导）→ 2023-04 起点 turnover_rate 0.053（换手
主导），macd 降到 0.040。

## 结论

1. **"信号随时间衰减"是误判**：4 起点测同一段市场，train IC 稳定证明模型结构未衰减。
2. **训练窗口越长，OOS 排序能力越强**：46 个月训练 Q 组单调，34 个月消失。
3. **测试段偏弱（2026 走弱）使所有起点弱市 Sharpe 低于训练段**，与市场 beta 有关，
   不是 alpha 衰减。
4. **启示**：a_share 生产应尽量用更长训练窗口（36 个月以上），与"长验证期更可靠"
   一致。

## 待确认

更细机制（为何 46 vs 34 个月训练在弱市差异大）需固定测试段、只改训练段长度隔离；
特征重要性漂移（macd→turnover）是否预示 alpha 结构变化值得单独研究。

## 与 D11-H5 的关系

D11-H5 回撤（6月+27.5%/7月-31.7%）与 top800 信号无关，是策略自身风格/行业暴露失控。
portfolio-backtester 无构建时风格约束（SelectionConstraints 仅含 min_price/min_amount），
加风格约束是 feature build 而非配置改动。是否新建"构建时风格暴露约束"需在确认
top800 信号价值后投入。
