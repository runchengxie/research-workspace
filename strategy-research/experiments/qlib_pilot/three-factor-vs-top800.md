# 三因子策略 vs top800 ML 对照（2026-08-10）

> 方法：复用 style_factors 因子计算，显式组合三个最强历史因子，对比 top800 XGB ML 策略
> 三因子：小盘（-size）+ 低换手（-turnover）+ 成长（净利润/营收同比）
> 打分：score = -z(size) + z(liquidity) + z(growth)，月度 top30 等权
> 口径：2019-01 到 2026-07，91 期月度；含 10bps 双边换手成本

## 结果对比

| 指标 | 三因子（含成本） | top800 ML v2（含成本） |
| --- | --- | --- |
| 总收益 | **+527%** | +51.79% |
| 年化收益 | +27.4% | +39.05% |
| **Sharpe** | **1.19** | 1.16 |
| 最大回撤 | -20.4% | -13.4% |
| 正收益期占比 | 57.1% | - |

## 核心结论

1. **三个显式因子（小盘+低换手+成长）组合的 Sharpe 1.19，达到甚至略超复杂 ML 模型（1.16）**。
   含成本口径下依然成立。这不是巧合——2019 起 6/7 年为正，稳健。
2. **ML 模型可能主要是在复现这三个因子的组合**。归因显示 top800 策略收益靠
   beta/growth 暴露（alpha 为负），而三因子显式组合直接站在三个被 18 年数据
   验证的强因子上（低换手 1.56 / 小盘 1.35 / 成长 1.28 Sharpe）。
3. **三因子更透明可控**：无黑盒、可解释、可约束暴露。对风格回撤的管理比 ML 更直接。
4. **代价**：回撤更大（-20% vs -13%），源于小盘暴露在极端行情下波动大。
   2026 转负（-12%）提示小盘因子近期逆风，这是需要管理的风险。

## 对策略体系的启示

- 如果目标是**简单、稳健、可解释**：三因子显式组合是 top800 ML 的有力替代，
  甚至可能是更好的选择（同等 Sharpe，透明得多）。
- 如果目标是**更高年化**：ML 策略靠 beta/growth 高暴露获取更高年化（39% vs 27%），
  但依赖风格持续，回撤更可控但 alpha 为负。
- 可组合：用三因子作为**选股基础**，ML 作为**增强**，或反之。

## 局限与后续

1. 三因子用理想等权回测（理想成交价），top800 用真实执行（含滑点/拆单）。
   口径仍不完全一致，但成本已计入，差异在滑点/延迟。
2. 未做滚动窗口稳定性验证（类似 top800 的 4 起点）。
3. 未测试不同因子权重（等权 vs 优化权重）。
4. 2026 三因子转负值得单独研究（小盘逆风期有多久）。
