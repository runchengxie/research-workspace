# Barra 风格 15 因子 long-only 落地分析（2008-2026）+ 敏感性

> 数据截至：2026-08-18
> 形成日范围：2008-01-31 至 2026-08-18，共 224 个月末截面
> 股票池：全 A，20 日成交额中位数不低于 2,000 万元
> 报告定位：研究筛查级落地形态分析

## 研究问题

既有 Barra 风格全市场分析（style-factor-market-regimes-2008-2026.md）测量的是
15 个风格因子的 Q4-Q1 多空价差。多空组合需做空且价差分布会高估可实现收益。
本报告把同一批 15 个因子放到纯多头、Top-100、月度再平衡、次交易日成交、
单边 30bp 成本的落地形态下重测，回答各因子在多头可交易约束下还剩多少 alpha。

同时补充三因子复合组合的滚动窗口与权重敏感性，刻画收益的时间衰减与主导因子。

## 方法与口径

- 因子方向：各因子按其长期多空价差的盈利侧取值。多空价差为正的因子保持原始
  方向（direction +1）；多空价差为负的因子取反（size 做多小盘、momentum 做多
  反转、beta 做多低贝塔），使 long-only 组合持有历史上占优的一侧。
- 选股：月末形成信号，Top-100 等权，下一交易日收盘成交。
- 成本：单边 30bp，按换手率扣除。
- 收益口径：未复权 pct_chg（raw 2008 数据无复权价）。
- 交易限制：2008 起 raw 数据无 ST/停牌/涨跌停标记，退化为价格与流动性过滤。

### 与多空价差对比

多空价差研究（长期基准）里最强的低换手（Sharpe 2.05）、价值（1.15）、成长
（1.32）、低波动（0.78），在 long-only Top-100 形态下全部大幅衰减：低换手
Sharpe 0.40、成长 0.20、价值 0.17、低波动 0.06。这些因子的价差优势主要在
空头腿（做空低分股），多头腿（持有高分股）独立收益有限。

小市值是唯一在 long-only 下仍保持较强收益的因子（Sharpe 0.60），与三因子
复合研究一致，确认小盘是多头可交易的主导 alpha。

### 重要警示：筹码集中度与机构持仓的假象

筹码集中度和机构持仓两个因子在 long-only 下 Sharpe 高达 1.20 和 1.11，但需谨慎：

- 两者都只有 11 年覆盖（2015 起）。
- 收益高度集中于个别年份：2015 和 2017 两年贡献了绝大部分收益（2017 分别
  +225% 和 +179%），其余年份多为 0 或负。
- 2017 是 A 股"漂亮 50"大票牛年，高机构持仓、高筹码集中度股票集中暴涨。
  这反映的是特定市场风格（regime），不是可持续的选股 alpha。
- 与市值相关性仅 0.14-0.20，排除单纯小盘暴露，但仍是单年集中爆发的统计假象。

不应仅凭 long-only Sharpe 就将这两个因子视为稳健 alpha 源。

## 二、三因子复合滚动窗口敏感性（Top-100，成本 30bp）

| 起点 | 年化 | Sharpe | 最大回撤 |
| --- | ---: | ---: | ---: |
| 2008 | 15.0% | 0.62 | -58.9% |
| 2010 | 14.9% | 0.64 | -49.9% |
| 2012 | 18.9% | 0.77 | -49.9% |
| 2015 | 15.7% | 0.65 | -49.9% |
| 2018 | 5.8% | 0.36 | -35.1% |
| 2020 | 8.2% | 0.45 | -35.1% |

结论：2008-2015 各起点年化 15-19%、Sharpe 0.62-0.77 稳定；但 2018 和 2020 起点
衰减至年化 6-8%、Sharpe 0.36-0.45。三因子复合的多头收益在近年明显衰减，印证
因子整体强度下降（与多空价差研究一致）。

## 三、三因子复合权重敏感性（2008-2026，Top-100，成本 30bp）

| 权重（小盘/低换手/成长） | 年化 | Sharpe |
| --- | ---: | ---: |
| **1/1/0（无成长）** | **27.3%** | **0.98** |
| 1/2/1（重低换手） | 19.8% | 0.77 |
| 2/1/1（重小盘） | 19.8% | 0.76 |
| 1/1/1（等权） | 15.0% | 0.62 |
| 1/1/2（重成长） | 6.7% | 0.37 |
| 1/0/1（无低换手） | 6.4% | 0.36 |
| 0/1/1（无小盘） | 5.7% | 0.34 |

关键结论：

1. 小盘和低换手是长期多头主导因子：去掉任意一个（无小盘 0.34、无低换手 0.36）
   Sharpe 都大幅下降。
2. **成长因子在 long-only 形态下是拖累**：无成长（1/1/0）Sharpe 0.98 最优，重成长
   （1/1/2）只有 0.37。这与多空价差研究中"成长必需"的结论不同。原因是成长因子的
   多头腿（持有高成长股）在 2008-2026 长期跑输，其价差优势主要来自空头腿
   （做空低成长股）。纯多头下持有高成长股的收益有限，反而稀释组合。
3. 因此三因子复合的多头形态应重小盘、重低换手、淡化成长，甚至可考虑剔除成长。

## 四、核心结论

1. long-only 形态大幅稀释因子收益：多空价差里最强的低换手（Sharpe 2.05）在
   long-only Top-100 只有 0.40，成长从 1.32 降到 0.20。多数风格因子的 alpha
   集中在空头腿，纯多头可获取的独立收益有限。
2. 小市值是唯一在纯多头下仍强的因子（Sharpe 0.60），是多头主导 alpha。
3. 筹码集中度/机构持仓的高 long-only Sharpe 是单年集中爆发的统计假象，不应
   作为稳健 alpha 源。
4. 三因子复合收益近年衰减（2018+ 起点 Sharpe 降至 0.36-0.45）。
5. 权重上应重小盘低换手、淡化成长；无成长（1/1/0）在长期多头形态下 Sharpe 0.98
   最优，与多空价差研究的权重建议相反。
