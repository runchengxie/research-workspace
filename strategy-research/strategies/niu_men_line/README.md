# 牛门线

牛门线是一套基于 20 日前高和 14 日平均真实波动幅度（ATR）的趋势观察方法。原始材料还提到了 10 日均线、20 日和 60 日成本线，以及行业、指数和宏观环境过滤。

当前阶段只做研究探索，不进入生产发布。这里维护策略身份、假设、版本和证据入口。公式计算放在 `alpha-research`，策略特有的事件定义和退出变体放在 `strategy-app`，组合回放交给 `portfolio-backtester`。

## 已明确的指标

基础指标使用以下定义：

~~~text
TR = max(H-L, abs(H-C[-1]), abs(L-C[-1]))
ATR14 = MA(TR, 14)
PRIOR_HIGH20 = HHV(H, 20)[-1]
NML = PRIOR_HIGH20 + 0.5 * ATR14
QRL = PRIOR_HIGH20 + 1.0 * ATR14
MA10 = MA(C, 10)
~~~

标的版成本线使用成交额和成交量。指数版使用收盘价和成交量加权。两种写法的单位可能不同，标的版的 `/100` 必须结合数据源和软件显示检查。

## 当前研究问题

原始材料没有把以下概念定义成可执行规则：

- 大趋势
- 盘整结束
- 价格与牛门线收敛
- 第一次触及的起算点
- K 线实体触碰
- 行业趋势和指数配合
- 追涨仓位的后续管理
- 确认线和退出规则

第一版先回答三个问题：

1. 第一次实体触及 `NML` 后，未来 1、3、5、10、20 个交易日的收益是否有条件预测能力？
2. 这种关系是否只在动量或牛市环境中出现？
3. 加入行业、指数、成交量和成本线条件后，增益来自哪一部分？
