## 一、因子与组合口径

Value 定义为 `1/PB`：PB 必须为正，截面 1%/99% 缩尾后先做行业内去均值，再做全截面 z-score。每个月末在 Value 自己的有效样本中分为五组，下一交易日起做多最低 PB 五分位、做空最高 PB 五分位。两腿月初等权、月内固定份额自然漂移。

全样本结果：

| 指标 | 修正后结果 |
| --- | ---: |
| 累计多空收益 | +543.57% |
| 252 日几何年化 | +11.01% |
| 年化波动 | 9.44% |
| 夏普 | 1.15 |
| 最大回撤 | -20.61% |
| 日胜率 | 50.5% |

这些是代理多空收益，不含借券约束、交易成本、涨跌停可成交性、ST/新股/退市处理，不能等同于实盘可获得收益。

## 三、周频区制

与 `market-intel/src/a_share_analysis/value_regime_weekly.py` 当前实现一致，先把日收益按周五复利聚合，再用 12 周复利收益划分：

| 区制 | 条件 | 周观察 | 占比 | 连续区制段数 |
| --- | --- | ---: | ---: | ---: |
| MOMENTUM | 12 周收益 > +5% | 250 | 27.3% | 50 |
| NEUTRAL | 其他 | 665 | 72.7% | 50 |

特征完整样本覆盖 2009-01-23 ~ 2026-07-31，共 915 周。下面的前瞻统计以每周为观察点，窗口彼此重叠，因此有效独立样本远小于表中 `n`。

### MOMENTUM 区制前瞻收益

| 窗口 | 平均收益 | 中位数 | 胜率 | n |
| --- | ---: | ---: | ---: | ---: |
| 4 周 | +0.6% | +0.1% | 51% | 248 |
| 13 周 | +1.8% | +1.6% | 67% | 248 |
| 26 周 | +5.1% | +5.2% | 79% | 248 |
| 52 周 | +9.2% | +9.4% | 86% | 248 |

只取每段 MOMENTUM 的首次进入点后，13 周平均 +2.4%、中位数 +1.6%、胜率 73%，但只有 49 个可用进入点。该稳健性检查优于把 248 个重叠周当作独立事件，仍不足以支持加杠杆或择时承诺。

NEUTRAL 区制并不弱：52 周平均 +9.4%、中位数 +9.7%、胜率 74%（n=615）。因此 MOMENTUM 标签更像 `过去 12 周已经上涨` 的状态描述，不能简单解释为短期买入信号。4 周胜率只有 51%，也不支持日频或月频追涨。

截至 2026-07-31，当前为 MOMENTUM 第 2 周：12 周复利 +12.4%、52 周 +5.9%。这只是样本末端状态，不是未来收益预测。

## 四、可以保留的结论

- 当前代理口径下，Value 的长期多空收益为正，但收益并非每年稳定，最大回撤仍超过 20%。
- 2010、2013、2020 三个完整负收益年之后次年均转正，是描述性事实。样本太少，不能称为可靠规律。
- MOMENTUM 区制的 26/52 周历史结果偏正，但 4 周没有明显优势。区制统计更适合作为背景信息，不宜作为仓位开关。
- Value 与 PSValue、DividendYield、EarningsYield 高度相关，也与 LowVol/Liquidity 有明显重叠。组合解释时应按价值/防御簇处理，避免重复计数。

## 五、数据和方法边界

- 长历史使用 raw daily / daily_basic。行业成员按历史区间匹配，但多空组合没有严格行业权重约束。
- 当前运行未完整消费逐日 PIT 股票池、`daily_clean` 或 revision-safe PIT v2。早期财务问题不直接进入 1/PB，但股票池、可交易性与退市偏差仍会影响结果。
- 2008 只从 2 月开始，2026 只到 7 月底。不能把它们与完整年度等量比较。
- 周频前瞻窗口重叠，且参数阈值 `+5%` 是样本内规则。未做多重检验或样本外阈值验证。
- 做空高 PB 股票在 A 股通常不可直接、低成本地实现。本结果是风格代理，不代表组合收益承诺。
