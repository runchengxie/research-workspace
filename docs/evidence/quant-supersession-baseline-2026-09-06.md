# Quant supersession baseline

> status: active
> owner: workspace
> last_verified: 2026-09-06

This baseline compares the checked-out `research-workspace` superproject and
all initialized submodules with the local `quant-platform` and
`quant-research` staging repositories. The workspace checkout is dirty, so
uncommitted files are included in the audit input and must be resolved before
cutover.

The full machine-readable inventory is generated by
`scripts/migration_parity_audit.py`. It excludes environments, caches, data,
artifacts, outputs, build products, and dependency trees. Python and Markdown
are counted separately. Physical LOC is not a substitute for function or
behavioral parity.

The current `strategy-research` submodule is at `fe8ebff`, while the private
migration provenance starts from `087b5df`. The post-migration delta therefore
requires an explicit private-research transfer before supersession can be
claimed.
