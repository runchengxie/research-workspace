## 代理定义

由于历史上没有最终 `Weekly Client Basket 10` 的 canonical basket 和 receipt，本次构造一个可复现的理论代理：

- 输入：飞书历史消息中标记为“正式 DailyWatch20 artifact”的每日20股名单。
- 选股：取消息中前10只，等权10%；这是“每日10股”代理，不是当前 `Weekly Client Basket 10`。
- 信号时间：消息标题日期。
- 执行时间：下一交易日开盘。
- 价格：A股 daily 分区行情的 open/close。
- 基准：000300.SH 的日收益，来自截至 2026-08-21 连续的 index daily 数据。
- 成本：10 bps × 换手 proxy；首日从现金建仓计入换手。
- 样本：2026-08-03 至 2026-08-14，共10个信号日、100个股票观测。

## 如何解读

这说明“历史飞书 DailyWatch20 消息的前10只、次日开盘执行”在这10个交易日内表现出正的样本内代理超额；但它不能证明当前灰度中的 `Weekly Client Basket 10` 有同样表现，因为：

1. 当前组合是 DailyWatch family + Cashflow + Microcap 的组合编排，而本代理只使用 DailyWatch20 前10。
2. 消息没有 canonical basket hash、投递 receipt 和显式权重；消息来源强度低于正式组合 artifact。
3. 样本只有10个信号日，且处于单一市场阶段，不能支持稳定性或 live eligibility 判断。
4. 10日结果只有50%可用权重/样本日覆盖，属于窗口不完整的诊断结果，不应作为正式10日结论。

## 后续建议

- 可把这版作为“历史理论推送基线”，用于和首个真实 `Weekly Client Basket 10` 前向结果并列比较。
- 不要把 DailyWatch-only 代理超额外推到 Cashflow/Microcap 或最终10股组合。
- 后续优先补齐历史 canonical basket、source artifact hash、delivery receipt 和同日 PIT 权重；补齐后再重跑严格 T 日收盘、T+1 开盘的最终组合样本外回放。
