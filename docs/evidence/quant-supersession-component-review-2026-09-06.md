# Quant supersession component review

> status: active
> owner: workspace
> last_verified: 2026-09-06

This review compares the current `strategy-research` submodule at `fe8ebff`
with the current `quant-research` target at `2b51d33`, using the target's
private path mapping. It is separate from the older migration provenance
comparison, which began at `087b5df`.

## Current result

- Five generated `*.egg-info` files are absent from the target and are not
  transfer requirements.
- Thirty-five source, research, documentation, or test files have different
  content.
- Two plotting modules differ only in chart-save portability. The target adds
  `_save_figure` and `_save_chart`; no source symbol is missing.
- Three research scripts differ. Two are dependency/path adaptations. The
  candidate-panel builder has a real behavior difference.
- Twenty-eight tests differ. Most adapt import-boundary expectations or
  repository layout. One renamed test reflects the new public-pipeline rule.

## Required code review

`research/experiments/style_factors/build_cni_980092_full_candidate_panel.py`
in the source exposes:

```text
availability_lag_days: int = 0
```

on both `_build_one` and `build_panel`, applies the lag to every point-in-time
feature lookup, and records the lag in the audit metadata. The target version
does not expose or apply this parameter. This is a likely missing research
functionality and should be ported with focused tests before cutover.

## Required test review

`tests/test_pipeline_import_boundary.py` changed from asserting that private
research code has no strategy-pipeline runtime imports to asserting that it
uses the public pipeline only. This is an architectural contract change, not
an automatically equivalent test. The target test and the workspace import
boundary checks must be reviewed together.

## Not transfer requirements

The missing `strategy_research_style_factors.egg-info` files are build metadata.
They should be regenerated by packaging and must not be treated as source
parity gaps.
