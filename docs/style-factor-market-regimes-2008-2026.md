本页是 `style_factors` 全量输出的人工解释层。2026-08-01 修正后复算读取日线与日频估值 `2008-01-02 ~ 2026-07-31`，形成 `2008-01-31 ~ 2026-07-31` 共 223 个月末截面、735,938 个股票月观察。多空收益从形成日下一交易日开始。2008 年首段和 2026 年末段均为部分年度。

本次复算修正了会改变历史结果的四类问题：因子样本不再被正 PB/PE 的公共过滤交叉污染。Quality 的稳定性按真实报告期计算，不使用日频前填行。辅助日频事件不再无限前填。月内组合由每日重置等权改为月初固定份额持有。以下数字不能与 2026-07-30 以前的旧表混用。

## 方向与组合口径

因子收益为 `top quintile - bottom quintile`。例如 Size 为正表示大市值强于小市值，Momentum 为负表示过去 21 日强势股随后弱于弱势股，Liquidity 为正表示低换手强于高换手。

每个因子在自己的非缺失样本上做 1%/99% 截尾，按申万历史一级行业成员区间做行业内去均值，再做全截面 z-score。行业匹配率为 89.6%，未匹配股票作为残差组。该处理只降低信号的行业均值暴露，不约束最终多空两腿的行业权重，因此本文不再使用 `严格行业中性` 表述。

## 2026 年初至今

截至 2026-07-31 的长覆盖因子向量为：

```text
Size +0.8, Value +7.8, Momentum -0.5, Quality +3.5,
EarningsYield +9.0, LowVol +8.6, Growth +10.5, Leverage +2.2,
Beta -0.1, Liquidity +15.4, DividendYield +6.9, PSValue +5.0
```

更稳妥的解读是：低换手、成长、低波和多种估值代理同时为正。Size 与 Beta 接近中性，21 日 Momentum 小幅为负。由于防御/价值簇内部相关性高，不能把这些结果视作多条独立信号。2026 仍是部分年度，不能把当前排名外推到全年。

## 对策略归因的含义

- Size 长期极负，任何未做市值约束的策略都可能把小盘暴露误报成 alpha。
- Value、PSValue、DividendYield、EarningsYield 以及 LowVol/Liquidity 存在明显共线性。多因子 OLS 的单项 beta 需要结合覆盖率和条件数复核。
- 归因只应纳入策略样本期覆盖率至少 80% 的因子，不能把 2026 才有的 LiquidityFlow 用零填充进 18 年回归。
- OLS alpha 应从截距年化，不能使用带截距回归后均值近似为零的残差年化。

## 使用边界

长历史仍读取 raw daily / daily_basic 与 legacy fundamentals，未完整使用 `daily_clean`、逐日 PIT 股票池或 revision-safe PIT v2。早期财务还可能受 top800_union 回填选择影响。组合没有交易成本、ST/新股过滤、涨跌停成交约束、退市末日收益或 A 股做空可实现性。报告因此适合内部风格筛查与假设生成，不适合直接形成仓位建议或宣称可交易收益。
