> status: active

> source_of_truth: no

本页是对 `style_factors` 全量输出的解释层，输入来自本地运行结果：

```text
artifacts/style_analysis_2008/factor_yearly.csv
```

样本覆盖 A 股日线和估值数据 `2008-03-03 ~ 2026-07-29`。共 15 个因子，均已做
申万 PIT 一级行业中性化（行业内 demean + 跨行业 z-score）。Growth/Leverage 自 2012-05 起、
Quality 自 2011-08 起、Beta 自 2008-08 起，`liquidity_flow`（大单资金流）自 2026-02 起、
`chip_concentration` / `institution_holding`（筹码/机构）自 2015-03 起，覆盖偏短，结论需谨慎。
2026 年截至 7-29 仍为未完整年度，本文所有 2026 判断都只代表 `2026-01-01 ~ 2026-07-29` 的
年初至今状态。

## 先读方向

这些因子是参考 Barra 思路构造的风格代理因子，并已做行业中性化。每个因子都在月末按五分位分组，构造等权多空组合：

| 因子收益为正时 | 含义 |
| --- | --- |
| Size | 大市值强于小市值 |
| Value | 低市净率（PB）强于高 PB |
| Momentum | 过去 21 日强势股继续强于弱势股 |
| Earnings Yield | 低 PE_TTM 强于高 PE_TTM，该因子用盈利收益率作为估值代理，与盈利质量无关 |
| LowVol | 低波动强于高波动 |
| Growth | 净利润/营收增长强于低增长 |
| Leverage | 低资产负债率强于高资产负债率 |
| Beta | 低 beta 强于高 beta |
| Liquidity | 低换手强于高换手 |
| Quality | 复合质量（ROE+低杠杆+盈利稳定+现金流质量）强于弱质量 |
| LiquidityFlow | 大单净买占比高强于低 |
| ChipConcentration | 筹码集中度高强于低 |
| InstitutionHolding | 机构持股占比高强于低 |
| DividendYield | 股息率高强于低 |
| PSValue | 低 PS_TTM 强于高 PS_TTM |

反过来，Size 为负表示小市值强，Momentum 为负表示短期反转强，LowVol 为负表示高波动强，
Beta 为负表示高 beta 强，Liquidity 为负表示高换手强。

需要特别小心共线性。全样本里 LowVol、Liquidity、Beta、Earnings Yield 之间相关性很高：
LowVol-Liquidity 约 `0.83`，LowVol-Beta 约 `0.77`，Beta-Liquidity 约 `0.72`，
Earnings-Yield-Beta 约 `0.72`。这些因子经常同时描述低波、低换手、低 beta、低估值或高盈利收益率这一类
防御组合。解读时应把它们当成相近风格，避免逐个拆成独立因果。

## 风格切换脉络

### 1. 小盘长期强，阶段上会反复切换

Size 是全样本最弱因子，年化 `-19.71%`。由于 Size 定义为大市值 - 小市值，这代表小市值相对大市值
长期明显占优。2008-2016 大部分年份都是小盘强，2017 是少数非常明确的大盘强年份，2020 和 2026
也出现 Size 转正。

这点很重要：如果一个策略长期跑赢但没有做市值中性，它很可能吃到了小盘 beta。反过来，2017 或
2026 这类 Size 转正阶段，会明显惩罚过度小盘暴露。

### 2. 短动量长期更接近反转信号

Momentum 是过去 21 日强势 - 弱势。全样本年化 `-10.94%`，多数年份为负，说明 A 股在这个频率上
更偏短期反转。2026 年初至今的 `+32.6%` 是一个明显例外，代表短期强势股阶段性延续。

### 3. 低换手是长期有效但会被交易热度阶段性打断

Liquidity 为正代表低换手强。长期年化 `+19.23%`，是全样本最稳健的因子（夏普 1.56），并且
2008、2011、2016、2017、2018、2022、2024、2026 都很强。2025 年为负，说明市场阶段性切到高换手、
高交易热度方向，但 2026 年截至 7 月底低换手重新领先（+15.1%），防御风格回归。

### 4. 价值和成长轮流占优

Value 在 2009、2014、2016、2022、2023、2024 明显强。Growth 在 2010、2012、2013、2020、2025、
2026 年初至今明显强。两类风格随市场环境轮动。

较典型的切换是：

- 2020：Growth `+16.3%`，Value 偏弱，成长显著压过价值。
- 2022-2024：Value 连续为正，尤其 2022 `+27.1%`（旧口径）、2023 `+19.0%`、2024 中性化口径 `+16.5%`。
- 2025-2026 年初至今：Growth 重新为正（2025 `+11.9%`、2026 `+6.3%`），Value 在 2025 短暂转弱后于 2026 回正（+10.0%）。

### 5. 防御风格常常抱团出现

LowVol、Liquidity、Beta、Earnings Yield 在相关性上高度绑定。2017、2021、2022、2024 这类年份，低波、
低换手、低估值/高盈利收益率往往一起强。2025 年这组防御属性整体承压（LowVol、Beta 转负），但 2026 年
截至 7 月底重新回归：LowVol `+7.4%`、Liquidity `+15.1%`、Value `+10.0%`，说明低波/低换手/低估值
防御组合阶段性重新占优。

## 2026 年初至今：历史对比

2026 年初至今（截至 7-29，中性化口径）的风格向量是：

```text
Size +2.4, Value +10.0, Momentum +0.9, Earnings Yield +12.2,
LowVol +7.4, Growth +6.3, Leverage -2.3, Beta +0.9, Liquidity +15.1
```

直接解读是：

- 大市值小幅强于小市值（+2.4），但幅度远小于 2017、2020，市值风格趋于中性。
- 短动量温和转正（+0.9），与多数历史年份的负值不同但幅度有限，并非 2025 年之前的强反转环境。
- 低波、低换手、低估值/高盈利收益率同时为正（+7.4 / +15.1 / +10.0 / +12.2），防御与价值组合重新占优。
- Growth 为正（+6.3）、Value 为正（+10.0），两者同正，与 2020、2025 的「成长相对价值」分化格局不同。
- Leverage 小幅为负（-2.3），解释力有限。

从跨因子年度形态看，2026 年初至今更接近 2017、2022、2024 这类低换手/低波/价值防御共振年，
与 2025 的高 beta/高成长切换年相反。注意 2026 仍为未完整年度，8-12 月可能改变形态。

## 对策略解读的含义

如果某条策略在 2026 年初至今表现好，需要先检查它是否暴露在这些方向上：

- 是否偏小市值（Size 仅 +2.4，市值风格中性，不再像 2017 那样强烈偏大盘）。
- 是否偏防御/低换手（LowVol +7.4、Liquidity +15.1 重新占优）。
- 是否偏价值或盈利估值（Value +10.0、Earnings Yield +12.2 同正）。
- 是否偏成长（Growth +6.3 仍为正，但与 Value 不再分化）。
- 是否回避高杠杆（Leverage -2.3 小幅为负）。

如果策略在 2025 好、但 2026 年初至今弱，一个常见解释是它吃到过 2025 年高 beta/高成长切换的 beta，
而 2026 截至 7 月底风格回到防御/价值共振。需要接入策略日收益 CSV，生成 `strategy_attribution_yearly.csv` 后，
才能把策略收益拆成风格 beta 和 residual alpha。

## 使用边界

这份解读基于当前 15 个代理因子的多空收益，已做申万 PIT 一级行业中性化，但仍暂未包含交易成本、
涨跌停成交约束、ST 过滤、真实组合持仓和风险模型协方差。它适合回答市场奖励了什么风格，组合归因和
风控归因仍需单独完成。对于具体策略，下一步应使用策略日收益运行普通最小二乘（OLS）归因，再结合
持仓暴露、行业暴露和换手成本复核。新因子（liquidity_flow / chip_concentration / institution_holding）
数据覆盖偏短，其逐年结论统计效力有限，不应与长周期因子并列解读。
